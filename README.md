# arggon-cv

Online CV that tells Gonzalo Argañaraz's story as an animated, scroll-driven
timeline — from a CRT monitor and crack-era gaming, through self-taught
networking and SQL injections at 16, to a senior .NET/AI engineering career.

Static site: vanilla HTML/CSS/JS, no framework, no build step.

Live at https://arggon.github.io/arggon-cv/ (GitHub Pages; deploy workflow in `.github/workflows/deploy.yml`).

Managed with [ArggonManager](../ArggonManager) (work items under `tasks/`,
spec in `docs/specs/`). Run locally: open `index.html`, or `python3 -m http.server`.
